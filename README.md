# TrueMail

AI Email Threat Detection is an AI-powered platform that detects suspicious and phishing emails, analyzes email threats, and provides geolocation and forensic intelligence to improve email security. It aims to identify potential cyber threats and help users stay protected from email-based attacks.

## Project Structure

- `frontend/` — user interface for analyzing suspicious emails
- `backend/` — APIs, ML pipeline, and Gmail integration logic
- `docs/` — architecture and project docs
- `tests/` — automated validation and quality checks

## Goals

- Detect phishing and malicious email patterns
- Analyze sender, subject, and message metadata
- Provide threat-risk scoring and forensic insights
- Integrate with Gmail APIs for secure monitoring
